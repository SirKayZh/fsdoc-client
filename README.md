# 飞书文档 Mac 客户端 (fsdoc-client)

轻量级飞书文档桌面客户端：只包飞书文档网页，**所有链接强制在应用内打开**，不会跳到系统浏览器，也不会唤起飞书主客户端。

## 安装

**方式一：dmg 安装**（`npm run build` 自己打包，见下文）→ 打开 dmg，把「飞书文档」拖进「应用程序」。

> 应用使用 ad-hoc 签名（未经 Apple 公证）。别的电脑首次打开若提示"无法验证开发者"：右键应用 → 打开；或终端执行
> `xattr -cr /Applications/飞书文档.app`。

**方式二：从源码运行**

```bash
npm install
npm start
```

首次打开会进入飞书登录页，登录一次后 session 持久保留，之后直接进文档首页。

## 核心机制

| 行为 | 处理方式 |
|------|----------|
| 点击文档 / `window.open` / target=_blank（飞书域名） | 应用内**新标签页**打开，不弹新窗口 |
| Cmd+点击 / 中键点击链接 | 后台新标签页 |
| `feishu://` 等唤起客户端的协议 | 直接拦截吞掉 |
| 非白名单域名（外部链接） | 拦截，不跳系统浏览器 |
| Electron 标识 | UA 伪装成 Chrome，避免飞书降级 |

## 标签页

- **拖动排序**：按住标签左右拖动，蓝色竖线标出插入位置，松手生效；顺序会随退出保存。
- 点标签切换；中键 / 点 ✕ 关闭；`Cmd+T` 新建；`Cmd+W` 关闭；右键标签有菜单（分屏、复制链接、刷新、关闭、关闭其他）。
- 退出后重开，标签页（和分屏状态）自动恢复。

## 分屏（两个文档左右对照）

| 操作 | 效果 |
|------|------|
| `Cmd+Option+\` 或 tab 栏右侧 ◫ 按钮（避开飞书「清除格式」的 `Cmd+\`） | 开 / 关分屏（与下一个标签页分屏；只有一个标签时自动新开一个） |
| 右键某个标签 → 与当前标签页分屏查看 | 指定和哪个标签分屏 |
| 右键页面里的链接 → 在分屏窗格中打开 | 新文档直接出现在另一个窗格 |
| 拖中间的分隔条 | 调整左右比例（20%–80%） |
| 点击某个窗格 | 该窗格成为"聚焦窗格"（标签栏高亮） |
| 分屏中点标签栏里其他标签 | 替换"聚焦窗格"显示的内容 |
| 分屏中在某窗格里点开新文档 | 在该窗格内替换显示，分屏不退出 |
| 关闭分屏中的某个标签 | 自动退出分屏，保留另一个 |

## 配置

都在 `main.js` 顶部：

- `START_URL`：启动页，默认 `https://feishu.cn/docs/`。也可用环境变量覆盖：
  ```bash
  FSDOC_URL=https://xxx.feishu.cn/docx/xxxx npm start
  ```
- `ALLOWED_HOSTS`：应用内放行的域名白名单，已含飞书全系（`feishu.cn` / `larkoffice.com` / `larksuite.com`）和微信扫码登录域。需要放开其他站点（如帮助中心外链）就往里加。

## 打包成 .app / .dmg

```bash
npm install
npm run build        # 产物在 dist/：飞书文档.app 和 飞书文档-<版本>-<架构>.dmg
```

`scripts/build-app.sh` 不依赖 electron-builder：复用 `node_modules` 里的 Electron.app，放入应用代码、改名、换图标、ad-hoc 签名并生成 dmg。架构跟随本机 `npm install` 的 Electron（Apple 芯片 → arm64，Intel → x86_64）。

图标由 `scripts/make-icon.swift` 合成（`npm run icon`）：白底圆角卡片 + 飞书官方品牌标识（`build/feishu-mark.png`，来源 Wikimedia 的 Lark Suite 2022 logo，与飞书同款）+「飞书文档」+「轻量版」徽章，产物 `build/icon.icns` 已提交。飞书名称与标识版权归字节跳动所有，本项目仅为个人使用的非商业客户端。

## 数据位置

- 登录态、标签状态：`~/Library/Application Support/飞书文档/`（删除即可退出登录 / 重置标签）。
